## 🧠 Обучение модели

### 1. Сбор данных

```bash
# Собрать данные для каждого жеста (50-100+ образцов)
python train_collect_data.py --gesture Hello --output data
python train_collect_data.py --gesture Thanks --output data
python train_collect_data.py --gesture Yes --output data
# ... и т.д.
```

**Управление:**
- `SPACE` - сохранить образец
- `Q` - завершить сбор

### 2. Обучение

```bash
python train_model.py --data data --output models/gesture_model.pth --epochs 100
```

### 3. Использование

```bash
python main_modern_gui.py --model models/gesture_model.pth
```

📖 [Подробная инструкция по обучению](signvoice_ai/README.md#обучение-модели)

## 🔧 Технологии

- **OpenCV** - захват и обработка видео
- **Mediapipe Hands** - обнаружение и отслеживание руки (21 точка)
- **PyTorch** - нейронная сеть для классификации жестов
- **pyttsx3** - синтез речи (TTS)
- **CustomTkinter** - современные UI компоненты (Modern GUI)
- **Tkinter** - стандартные UI компоненты (Standard GUI)
- **NumPy** - работа с массивами
- **Pillow** - обработка изображений

---

## 🎯 Архитектура модели

```
Input: 63 значения (21 точка × 3 координаты: x, y, z)
  ↓
Hidden Layer: 128 нейронов + ReLU + Dropout(0.2)
  ↓
Output: 5 классов (жесты)
```

Координаты нормализуются относительно запястья для инвариантности к масштабу и положению.

## 💡 Советы по использованию

### Для лучшего распознавания

1. 🔆 **Освещение** - используйте хорошее освещение
2. 🖐️ **Фон** - однотонный контрастный фон
3. 📏 **Расстояние** - 30-60 см от камеры
4. ⏱️ **Стабильность** - держите жест 1-2 секунды
5. 🎯 **Четкость** - делайте жесты четко и медленно

### Настройка параметров

```
Для точности:
├─ Порог стабильности: 7-10
├─ Мин. уверенность: 0.7-0.9
└─ Хорошее освещение

Для скорости:
├─ Порог стабильности: 3-5
├─ Мин. уверенность: 0.4-0.6
└─ Может быть менее точным
```

## 🐛 Устранение неполадок

### Камера не открывается
```bash
# Попробуйте другую камеру
python main_modern_gui.py --camera 1

# Закройте другие приложения, использующие камеру
```

### Ошибки с PyTorch
```bash
# CPU версия (рекомендуется)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

### Ошибки с CustomTkinter
```bash
pip install --upgrade customtkinter
```

### Приложение тормозит
1. Закройте другие приложения
2. Уменьшите разрешение в `utils/camera.py`
3. Используйте Classic интерфейс
