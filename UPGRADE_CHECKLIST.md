# ✅ SignVoiceAI Enterprise - Чеклист установки и использования

> Пошаговое руководство для начала работы с Enterprise Edition

---

## 📋 Предварительные требования

### Системные требования

- [ ] Python 3.8 или выше установлен
- [ ] Веб-камера подключена
- [ ] Windows / Linux / macOS
- [ ] Минимум 100 МБ свободного места на диске
- [ ] Рекомендуется 4 ГБ RAM

### Проверка Python

```bash
python --version
# Должно быть: Python 3.8.x или выше

python -m pip --version
# Должен быть установлен pip
```

## 🚀 Установка

### Шаг 1: Подготовка окружения

- [ ] Перейдите в директорию проекта
  ```bash
  cd prototype3/signvoice_ai
  ```

- [ ] (Опционально) Создайте виртуальное окружение
  ```bash
  python -m venv venv
  
  # Windows
  venv\Scripts\activate
  
  # Linux/macOS
  source venv/bin/activate
  ```

### Шаг 2: Установка зависимостей

- [ ] Установите требуемые пакеты
  ```bash
  pip install -r requirements.txt
  ```

- [ ] Проверьте установку ключевых пакетов
  ```bash
  python -c "import cv2; print('OpenCV:', cv2.__version__)"
  python -c "import mediapipe; print('Mediapipe OK')"
  python -c "import torch; print('PyTorch:', torch.__version__)"
  python -c "import customtkinter; print('CustomTkinter OK')"
  ```

### Шаг 3: Проверка камеры

- [ ] Убедитесь, что камера работает
  ```python
  # Запустите в Python консоли:
  import cv2
  cap = cv2.VideoCapture(0)
  ret, frame = cap.read()
  print("Camera OK" if ret else "Camera Error")
  cap.release()
  ```

## 🎯 Первый запуск

### Запуск Enterprise Edition

#### Windows

- [ ] Двойной клик на `launch_enterprise.bat`
  
  **ИЛИ** в командной строке:
  ```bash
  launch_enterprise.bat
  ```

#### Linux/macOS

- [ ] Сделайте файл исполняемым (один раз):
  ```bash
  chmod +x launch_enterprise.sh
  ```

- [ ] Запустите:
  ```bash
  ./launch_enterprise.sh
  ```

#### Прямой запуск

- [ ] Запустите Python скрипт:
  ```bash
  python main_enterprise_gui.py
  ```

## 👤 Регистрация и вход

### Первое использование

- [ ] Откроется окно авторизации
- [ ] Выберите вкладку **"Регистрация"**
- [ ] Заполните поля:
  - [ ] Имя пользователя (обязательно)
  - [ ] Email (опционально)
  - [ ] Полное имя (опционально)
  - [ ] Пароль (минимум 6 символов, обязательно)
- [ ] Нажмите "Зарегистрироваться"
- [ ] Вернитесь на вкладку "Вход"
- [ ] Введите имя пользователя и пароль
- [ ] Нажмите "Войти"

### Гостевой режим (для тестирования)

- [ ] В окне авторизации нажмите "Продолжить как гость"
- [ ] Система автоматически создаст временного пользователя

## 🎥 Первая сессия распознавания

### Подготовка

- [ ] Убедитесь в хорошем освещении
- [ ] Используйте однотонный фон
- [ ] Расположитесь на расстоянии 40-70 см от камеры

### Начало работы

- [ ] Откройте вкладку **🎥 Распознавание**
- [ ] Нажмите кнопку **"▶ Старт"**
- [ ] Разрешите доступ к камере (если запросит)
- [ ] Дождитесь инициализации (несколько секунд)

### Распознавание жестов

- [ ] Покажите жест перед камерой
- [ ] Держите жест стабильно 1-2 секунды
- [ ] Наблюдайте за статусом:
  - **Жест** - название распознанного жеста
  - **Уверенность** - точность распознавания
  - **Статус** - стабильность (⏳ → ✓)
- [ ] Жест озвучится автоматически (если включено)

### Завершение сессии

- [ ] Нажмите кнопку **"⏸ Стоп"**
- [ ] Сессия автоматически сохранится в базу данных

## 🔧 Решение проблем

### Камера не работает

- [ ] Проверьте подключение камеры
- [ ] Закройте другие приложения, использующие камеру
- [ ] В настройках попробуйте другой индекс камеры
- [ ] Перезапустите приложение

### Приложение не запускается

- [ ] Проверьте версию Python (должна быть 3.8+)
- [ ] Переустановите зависимости:
  ```bash
  pip install -r requirements.txt --force-reinstall
  ```
- [ ] Проверьте логи в папке `logs/`

### Ошибки базы данных

- [ ] Проверьте наличие файла `signvoice_enterprise.db`
- [ ] Если БД повреждена, удалите её (будет создана новая):
  ```bash
  rm signvoice_enterprise.db  # Linux/Mac
  del signvoice_enterprise.db  # Windows
  ```

### Низкая производительность

- [ ] Закройте другие приложения
- [ ] Уменьшите разрешение камеры в настройках
- [ ] Отключите анимации
- [ ] Используйте компактный режим

### Проблемы с распознаванием

- [ ] Улучшите освещение
- [ ] Используйте однотонный фон
- [ ] Держите жесты дольше (2-3 секунды)
- [ ] Увеличьте порог стабильности в настройках

## 🎓 Советы по эффективному использованию

1. **Регулярность** ⏰
   - [ ] Занимайтесь каждый день
