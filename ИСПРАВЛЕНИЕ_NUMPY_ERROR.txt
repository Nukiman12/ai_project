ПРОБЛЕМА С NUMPY:
  NumPy массивы нельзя использовать в условиях напрямую:
  
  ❌ if array:           # ValueError
  ❌ array1 or array2:   # ValueError
  ❌ array1 and array2:  # ValueError
  
  ✅ if array is None:   # OK
  ✅ if array is not None: # OK
  ✅ if len(array) > 0:  # OK
  ✅ if array.any():     # OK (проверка элементов)
  ✅ if array.all():     # OK (проверка элементов)

ПРАВИЛЬНЫЕ ПАТТЕРНЫ:

1. Проверка на None:
   if array is None:
       ...

2. Проверка наличия элементов:
   if array is not None and len(array) > 0:
       ...

3. Последовательная проверка:
   result = first_array
   if result is None:
       result = second_array

4. С использованием if-else:
   result = first_array if first_array is not None else second_array
