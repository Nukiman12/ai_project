ВАРИАНТ 1: "КНОПКА ОБУЧЕНИЯ НАЖАТА!" появилось
    → Отлично! Метод вызывается
    → Смотрите дальше что пишет

ВАРИАНТ 2: Ничего не появилось
    → Кнопка не привязана или вкладка не та
    → Проверьте, что открыта вкладка "🎓 Обучение"

ВАРИАНТ 3: "❌ TRAINING_AVAILABLE = False"
    → Модули недоступны
    → pip install torch scikit-learn

ВАРИАНТ 4: "❌ Недостаточно данных: X < 30"
    → Запишите больше жестов
    → Минимум 30 образцов нужно

ВАРИАНТ 5: "❌ ОШИБКА при подготовке: ..."
    → Скопируйте текст ошибки
    → Покажите для диагностики
