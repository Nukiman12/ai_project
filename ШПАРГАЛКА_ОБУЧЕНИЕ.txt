┃ 🚀 БЫСТРЫЙ СТАРТ (3 МИНУТЫ)                                     ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

1. Двойной клик: signvoice_ai\launch_simple_trainer.bat
2. Кнопка "➕ Новый жест" → Введите: Peace
3. Покажите ✌️ → Кнопка "📹 Записать" → Держите 5 сек
4. Повторите шаг 3 ещё 5 раз с разных углов
5. Добавьте ещё 2-3 жеста (OK, ThumbsUp, Hello)
6. Кнопка "🎓 Обучить модель" → Готово!

┃ ✅ ЧЕКЛИСТ КАЧЕСТВЕННОЙ ЗАПИСИ                                  ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

ПЕРЕД ЗАПИСЬЮ:
  ☐ Хорошее освещение (лампа/окно спереди)
  ☐ Однотонный фон (стена, не узоры)
  ☐ Камера на уровне груди
  ☐ Расстояние 50-100 см от камеры

ВО ВРЕМЯ ЗАПИСИ:
  ☐ Рука полностью в кадре (все пальцы видны)
  ☐ Жест чёткий и уверенный
  ☐ Держите жест неподвижно 3-5 секунд
  ☐ Не торопитесь между примерами

РАЗНООБРАЗИЕ (для каждого жеста):
  ☐ Центр кадра (2 примера)
  ☐ Левая сторона (1 пример)
  ☐ Правая сторона (1 пример)
  ☐ Ближе к камере (1 пример)
  ☐ Дальше от камеры (1 пример)
  ☐ Поворот руки влево (1 пример)
  ☐ Поворот руки вправо (1 пример)

ОБУЧЕНИЕ:
  ☐ Минимум 3 жеста добавлено
  ☐ Минимум 5 примеров на жест
  ☐ Нажата кнопка "Обучить модель"
  ☐ Обучение завершено успешно
  ☐ Протестирован хотя бы один жест

БАЗОВЫЕ:
  Hello          - открытая ладонь ✋
  Peace          - два пальца ✌️
  ThumbsUp       - большой палец вверх 👍
  ThumbsDown     - большой палец вниз 👎
  OK             - круг из пальцев 👌
  Stop           - ладонь вперёд ✋
  Fist           - кулак ✊

ЭМОЦИОНАЛЬНЫЕ:
  Love           - рожки + большой палец 🤟
  Heart          - сердечко руками ❤️
  Victory        - победа ✌️
  Rock           - рок жест 🤘
  CallMe         - позвони мне 🤙

УКАЗАТЕЛЬНЫЕ:
  PointUp        - указательный вверх ☝️
  PointDown      - указательный вниз 👇
  PointLeft      - указательный влево 👈
  PointRight     - указательный вправо 👉

ФУНКЦИОНАЛЬНЫЕ:
  Yes            - да (кулак с поднятым большим)
  No             - нет (кулак с опущенным большим)
  Please         - пожалуйста
  Thanks         - спасибо
  Sorry          - извините
  Help           - помощь

СПЕЦИАЛЬНЫЕ:
  Vulcan         - вулканский привет 🖖
  Shaka          - шака 🤙
  MiddleFinger   - средний палец 🖕 (если нужно 😄)
  CrossedFingers - скрещенные пальцы 🤞

СБОР ДАННЫХ (по 50 примеров):
  cd signvoice_ai
  python train_collect_data.py --gesture Peace --samples 50
  python train_collect_data.py --gesture OK --samples 50
  python train_collect_data.py --gesture ThumbsUp --samples 50

ОБУЧЕНИЕ МОДЕЛИ (50 эпох):
  python train_model.py --data data --output models/gesture_model.pth --epochs 50

ТЕСТИРОВАНИЕ:
  python gesture_recognizer_simple.py
