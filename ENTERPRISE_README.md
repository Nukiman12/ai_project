## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd signvoice_ai
pip install -r requirements.txt
```

### 2. Запуск Enterprise Edition

#### Windows:
```bash
launch_enterprise.bat
```

#### Linux/macOS:
```bash
chmod +x launch_enterprise.sh
./launch_enterprise.sh
```

#### Или напрямую:
```bash
python main_enterprise_gui.py
```

### 3. Первый запуск

При первом запуске:
1. Откроется окно авторизации
2. Выберите вкладку **"Регистрация"**
3. Создайте учетную запись
4. Войдите в систему

**Или используйте гостевой режим** для быстрого тестирования

## 🗄️ База данных

### Структура

Enterprise Edition использует SQLite базу данных со следующими таблицами:

- `users` - пользователи
- `user_profiles` - профили
- `user_settings` - настройки
- `gesture_history` - история жестов
- `sessions` - сессии работы
- `achievements` - достижения
- `user_achievements` - прогресс пользователей
- `gesture_statistics` - статистика по жестам
- `exports` - экспортированные данные

### Файл базы данных

```
signvoice_enterprise.db
```

**Безопасность:**
- Пароли хешируются (SHA-256)
- Данные изолированы по пользователям
- Thread-safe операции

## 📊 API для разработчиков

### DatabaseManager

```python
from database.db_manager import DatabaseManager

db = DatabaseManager("my_database.db")

# Создание пользователя
user_id = db.create_user("username", "password", "email@example.com")

# Аутентификация
user_id = db.authenticate_user("username", "password")

# Получение информации
user_info = db.get_user_info(user_id)

# Добавление жеста
db.add_gesture(user_id, session_id, "Hello", 0.95)

# Получение статистики
stats = db.get_user_statistics(user_id)
```

### AnalyticsEngine

```python
from analytics.analytics_engine import AnalyticsEngine

analytics = AnalyticsEngine(db)

# Dashboard
dashboard = analytics.get_user_dashboard(user_id)

# Производительность
performance = analytics.analyze_performance(user_id)

# Тренды
trends = analytics.analyze_trends(user_id, days=30)

# Рекомендации
recommendations = analytics.generate_recommendations(user_id)

# Отчет
report = analytics.generate_report(user_id, period_days=30)
```

### ThemeManager

```python
from config.themes import ThemeManager, THEMES

theme_manager = ThemeManager()

# Установка темы
theme_manager.set_theme('cyber')

# Получение текущей темы
theme = theme_manager.get_theme()

# Доступные темы
themes = theme_manager.get_available_themes()

# Создание своей темы
theme_manager.create_custom_theme('my_theme', {
    'primary': '#ff0000',
    'secondary': '#00ff00',
    # ... другие цвета
})
```

### UserPreferences

```python
from config.themes import UserPreferences

prefs = UserPreferences(db, user_id)

# Получение настройки
theme = prefs.get('theme', 'dark')

# Установка настройки
prefs.set('theme', 'light')

# Обновление нескольких
prefs.update(
    theme='blue',
    language='en',
    speech_rate=180
)

# Сброс
prefs.reset_to_defaults()

# Экспорт/импорт
prefs.export_preferences('settings.json')
prefs.import_preferences('settings.json')
```

## 💡 Советы и рекомендации

### Для лучшего распознавания

1. **Освещение** - равномерное, без резких теней
2. **Фон** - однотонный, контрастный с рукой
3. **Расстояние** - 40-70 см от камеры
4. **Стабильность** - держите жест 1-2 секунды
5. **Четкость** - выполняйте жесты медленно и четко

### Для накопления очков

1. **Регулярность** - занимайтесь каждый день
2. **Длительность** - сессии по 15-20 минут
3. **Разнообразие** - практикуйте все жесты
4. **Качество** - стремитесь к высокой уверенности

### Настройка производительности

```python
# В настройках

# Для точности:
stability_threshold = 7-10
min_confidence = 0.7-0.9

# Для скорости:
stability_threshold = 3-5
min_confidence = 0.4-0.6
```

## 📈 Статистика и метрики

### Основные метрики

- **Total Gestures** - общее количество распознанных жестов
- **Total Sessions** - количество сессий
- **Total Time** - общее время работы
- **Avg Confidence** - средняя уверенность распознавания
- **Best Confidence** - лучшая уверенность
- **Unique Gestures** - количество различных жестов
- **Consistency Score** - оценка консистентности (0-1)
- **Performance Rating** - общая оценка производительности

### Рейтинги производительности

- **Excellent** (≥0.9) - Отличная работа! ⭐⭐⭐⭐⭐
- **Very Good** (≥0.8) - Очень хорошо! ⭐⭐⭐⭐
- **Good** (≥0.7) - Хорошо ⭐⭐⭐
- **Fair** (≥0.6) - Удовлетворительно ⭐⭐
- **Needs Improvement** (<0.6) - Требуется улучшение ⭐

## 🐛 Устранение неполадок

### Проблемы с базой данных

```bash
# Если БД повреждена, создайте новую:
rm signvoice_enterprise.db
python main_enterprise_gui.py
```

### Проблемы с авторизацией

```python
# Сброс пароля (в Python консоли):
from database.db_manager import DatabaseManager
db = DatabaseManager("signvoice_enterprise.db")
# Создайте нового пользователя
```

### Проблемы с производительностью

1. Уменьшите разрешение камеры
2. Отключите анимации в настройках
3. Используйте compact_mode
4. Ограничьте history_limit
