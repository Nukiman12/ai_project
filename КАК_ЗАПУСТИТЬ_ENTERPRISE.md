# 🚀 Как запустить SignVoiceAI Enterprise Edition

## ✅ Быстрый запуск

### Windows:
**Двойной клик** по файлу:
```
signvoice_ai/launch_enterprise_py311.bat
```

### Или из командной строки:
```powershell
cd signvoice_ai
py -3.11 main_enterprise_gui.py
```

## 🐛 Устранение проблем

### Окно не открывается
1. Проверьте, что запущен правильный Python:
   ```powershell
   py -3.11 --version
   ```
   Должен быть: `Python 3.11.x`

2. Проверьте, что mediapipe установлен:
   ```powershell
   py -3.11 -m pip list | findstr mediapipe
   ```

### Ошибка "No module named 'mediapipe'"
Установите зависимости:
```powershell
py -3.11 -m pip install mediapipe opencv-python customtkinter pillow pyttsx3
```

### Камера не работает
1. Закройте другие приложения, использующие камеру
2. Проверьте права доступа к камере в Windows
3. Перезапустите программу
