ШАГ 3: ПРОВЕРЬТЕ ВКЛАДКУ "ОБУЧЕНИЕ"
────────────────────────────────────────────────────────────────

ЕСТЬ ВКЛАДКА "🎓 Обучение"?

✅ ДА - вкладка видна:
   → Модули обучения доступны
   → TRAINING_AVAILABLE = True
   → Кнопка должна работать

❌ НЕТ - вкладки нет:
   → Модули обучения недоступны
   → TRAINING_AVAILABLE = False
   → Кнопка не появляется вообще

ПРИЧИНА: Недостаточно данных (< 30 образцов)
РЕШЕНИЕ: Запишите больше жестов

ОШИБКА 3: При нажатии появляется "Модули обучения недоступны"

РЕШЕНИЕ: Установите PyTorch и scikit-learn, перезапустите

ПРИЧИНА: Меньше 30 образцов
РЕШЕНИЕ: Запишите больше образцов (3+ жестов × 10+ образцов)

ОШИБКА 5: "No module named 'torch'"
ПРИЧИНА: PyTorch не установлен
РЕШЕНИЕ: pip install torch

ОШИБКА 6: "No module named 'sklearn'"
ПРИЧИНА: scikit-learn не установлен
РЕШЕНИЕ: pip install scikit-learn

1. ИСПОЛЬЗУЙТЕ ВИРТУАЛЬНОЕ ОКРУЖЕНИЕ:
   • Активируйте venv перед установкой пакетов
   • venv\Scripts\Activate.ps1 (PowerShell)
   • venv\Scripts\activate.bat (CMD)

2. УСТАНОВИТЕ ВСЁ СРАЗУ:
   • pip install -r requirements.txt
   • Установит все зависимости

3. ПРОВЕРЬТЕ ВЕРСИЮ PYTHON:
   • python --version
   • Должна быть 3.11 (для Mediapipe)
   • Используйте py -3.11 если несколько версий

4. ПЕРЕЗАПУСКАЙТЕ ПРИЛОЖЕНИЕ:
   • После установки пакетов
   • launch_enterprise_py311.bat
