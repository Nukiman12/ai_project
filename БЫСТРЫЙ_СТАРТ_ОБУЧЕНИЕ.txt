1. ЗАПУСК ТРЕНЕРА:
   • Windows: Двойной клик на launch_simple_trainer.bat
   • Или: cd signvoice_ai && python gesture_trainer_simple.py

2. ДОБАВЛЕНИЕ ЖЕСТА:
   • Нажмите "➕ Новый жест"
   • Введите название (например: Peace, OK, ThumbsUp)

3. ЗАПИСЬ ПРИМЕРОВ:
   • Выберите жест из списка
   • Покажите жест в камеру
   • Нажмите "📹 Записать"
   • Держите жест 3-5 секунд
   • Повторите 5-10 раз с разных углов

4. ОБУЧЕНИЕ:
   • Добавьте минимум 3-5 жестов
   • Для каждого запишите 5-10 примеров
   • Нажмите "🎓 Обучить модель"
   • Подождите 10-30 секунд
   • Готово!

5. ТЕСТИРОВАНИЕ:
   • Покажите жест после обучения
   • Программа автоматически распознает его

КОЛИЧЕСТВО ПРИМЕРОВ:
  • Простые жесты (✌️, 👍): 5-10 примеров
  • Средние (👌, 🤙): 10-20 примеров
  • Сложные (🤘, 🖖): 20-30 примеров

КАЧЕСТВО ЗАПИСИ:
  ✅ Рука полностью в кадре
  ✅ Хорошее освещение
  ✅ Разные углы и расстояния
  ✅ Чёткие движения
  
  ❌ Рука за кадром
  ❌ Размытое изображение
  ❌ Слишком быстро
  ❌ Плохое освещение

ПРОСТЫЕ СТАТИЧЕСКИЕ:
  • Hello/Wave - открытая ладонь ✋
  • Peace - два пальца ✌️
  • ThumbsUp - большой палец вверх 👍
  • OK - круг из пальцев 👌
  • Stop - ладонь вперёд ✋
  • Fist - кулак ✊

СЛОЖНЫЕ:
  • Love/ILoveYou - рожки + большой палец 🤟
  • PointUp - указательный палец вверх ☝️
  • Rock - рок жест 🤘
  • Vulcan - спок 🖖

ДИНАМИЧЕСКИЕ:
  • Wave - махание рукой
  • Swipe - свайп влево/вправо
  • Circle - круговое движение
  • Goodbye - махание на прощание

СПОСОБ 2: КОМАНДНАЯ СТРОКА

1. Сбор данных:
   cd signvoice_ai
   python train_collect_data.py --gesture Peace --output data --samples 50
   python train_collect_data.py --gesture OK --output data --samples 50
   python train_collect_data.py --gesture ThumbsUp --output data --samples 50

   Управление: SPACE - записать, Q - выход

2. Обучение модели:
   python train_model.py --data data --output models/gesture_model.pth --epochs 50

3. Тестирование:
   python gesture_recognizer_simple.py

Q: Сколько нужно примеров?
A: Минимум 5-10 на жест. Чем больше - тем лучше.

Q: Можно использовать обе руки?
A: Да! Программа поддерживает левую и правую руку.

Q: Как улучшить точность?
A: 1) Больше примеров
   2) Разные углы съёмки
   3) Хорошее освещение
   4) Чёткие жесты

Q: Модель не распознает жест
A: 1) Проверьте освещение
   2) Рука полностью в кадре?
   3) Добавьте больше примеров
   4) Переобучите модель

Q: Где хранятся модели?
A: • signvoice_ai/models/gesture_model.pth (PyTorch)
   • signvoice_ai/gesture_templates.pkl (DTW шаблоны)

ПРОБЛЕМА: Камера не открывается
РЕШЕНИЕ: 
  1. Закройте другие программы с камерой
  2. Проверьте права доступа
  3. Попробуйте --camera 1

ПРОБЛЕМА: Низкая точность
РЕШЕНИЕ:
  1. Соберите больше примеров (30-50)
  2. Увеличьте epochs до 100
  3. Проверьте качество данных
  4. Хорошее освещение

ПРОБЛЕМА: Ошибка при загрузке модели
РЕШЕНИЕ:
  1. Проверьте путь к модели
  2. Переобучите модель
  3. Проверьте версию PyTorch
