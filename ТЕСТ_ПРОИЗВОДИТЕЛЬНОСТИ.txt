ПРОБЛЕМА: Камера всё ещё тормозит
РЕШЕНИЯ:

1. Проверьте версию Python:
   py -3.11 --version
   Должно быть: Python 3.11.x

2. Проверьте загрузку CPU:
   Откройте Диспетчер задач
   Python должен использовать ~20-40% на одном ядре

3. Попробуйте уменьшить разрешение:
   В main_enterprise_gui.py найдите:
   frame_resized = cv2.resize(frame_rgb, (640, 480))
   Замените на:
   frame_resized = cv2.resize(frame_rgb, (480, 360))

4. Увеличьте задержку между кадрами:
   В process_video() найдите:
   time.sleep(0.01)
   Замените на:
   time.sleep(0.03)

5. Отключите озвучивание:
   В настройках снимите галочку "Автоозвучивание"

6. Закройте другие программы:
   Особенно использующие камеру или много CPU
