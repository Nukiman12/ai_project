█ ПРОБЛЕМА 1: Программа зависала при запуске
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Симптомы:
  • Останавливалась на "Создание таблиц..."
  • Окно не появлялось
  • Программа не отвечала

Причина:
  • Deadlock (взаимная блокировка) в базе данных
  • threading.Lock() не поддерживает реентрабельность
  • init_database() вызывал init_default_achievements() 
    с тем же Lock'ом

Решение:
  ✅ Заменён threading.Lock() на threading.RLock()
  ✅ RLock позволяет одному потоку захватывать блокировку 
     несколько раз

Файл: signvoice_ai/database/db_manager.py, строка 36


█ ПРОБЛЕМА 2: TypeError при отображении достижений
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Симптомы:
  • Окно открывалось
  • Ошибка: "unsupported operand type(s) for /: 'NoneType' and 'int'"
  • Падение при переходе на вкладку "Достижения"

Причина:
  • Новый пользователь без истории жестов
  • LEFT JOIN возвращал NULL для поля 'progress'
  • Код пытался: None / 100

Решение:
  ✅ Добавлена обработка None:
     progress = achievement.get('progress', 0) or 0
  ✅ Теперь None преобразуется в 0

Файл: signvoice_ai/main_enterprise_gui.py, строка 885


█ ПРОБЛЕМА 3: Python 3.13 не поддерживает mediapipe
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Симптомы:
  • ModuleNotFoundError: No module named 'mediapipe'
  • pip install не находит версию для Python 3.13

Причина:
  • mediapipe поддерживает только Python 3.8-3.11
  • В venv установлен Python 3.13

Решение:
  ✅ Используется глобальный Python 3.11:
     py -3.11 main_enterprise_gui.py
  ✅ Создан launch_enterprise_py311.bat для быстрого запуска

Файл: signvoice_ai/launch_enterprise_py311.bat
