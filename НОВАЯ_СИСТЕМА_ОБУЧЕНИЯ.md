# 🚀 Новая система обучения в SignVoiceAI Enterprise

## ✨ Что добавлено

- 🧠 **ResNet-like архитектура** с residual connections
- 🎯 **Attention mechanism** для фокусировки на важных признаках

## 🎯 Как использовать (Когда будет готово)

### В Enterprise Edition появится новая вкладка "🎓 Обучение":

1. **Сбор данных:**
   - Нажмите "➕ Новый жест"
   - Введите название
   - Покажите жест → нажмите "📹 Записать"
   - Повторите 10-20 раз

2. **Обучение модели:**
   - Нажмите "🚀 Начать обучение"
   - Наблюдайте графики в реальном времени
   - Дождитесь завершения

3. **Использование:**
   - Модель автоматически активируется
   - Распознавание сразу с новыми жестами!

## 🏗️ Архитектура модели

```
Input (63) 
   ↓
Input Projection (256)
   ↓
ResBlock 1 (256 → 512)
   ↓
ResBlock 2 (512 → 512)
   ↓
Attention Layer (512)
   ↓
ResBlock 3 (512 → 512)
   ↓
ResBlock 4 (512 → 256)
   ↓
Classifier (256 → 128 → num_classes)
```

**Residual Block:**
```
Input
  ├→ FC → BN → ReLU → Dropout → FC → BN →┐
  └────────────────────────────────────→ ADD → ReLU → Output
```

**Attention:**
```
Input → FC → ReLU → FC → Sigmoid → Multiply with Input
```

## 🎓 Процесс обучения

### Автоматические улучшения:

1. **AdamW optimizer** с weight decay для регуляризации
2. **Learning rate scheduler** (уменьшение при плато)
3. **Early stopping** (останавливает при переобучении)
4. **Data augmentation** (встроенная нормализация)
5. **Best model saving** (сохраняется лучшая версия)

### Гиперпараметры (по умолчанию):

```python
epochs = 50                    # Максимум эпох
learning_rate = 0.001          # Начальная скорость
weight_decay = 1e-4            # L2 регуляризация
dropout = 0.3                  # Вероятность dropout
batch_size = 16                # Размер батча
patience = 10                  # Терпение для early stopping
test_split = 0.2               # 20% на тестирование
```

## 📈 Метрики обучения

Во время обучения отслеживаются:

- **Train Loss** - потери на обучающей выборке
- **Train Accuracy** - точность на обучении
- **Val Loss** - потери на валидации
- **Val Accuracy** - точность на валидации  
- **Learning Rate** - текущая скорость обучения
- **Best Val Accuracy** - лучшая валидационная точность
